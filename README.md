# 黑神话：悟空 DualSense 波形触觉

为 PC 版《黑神话：悟空》增加 PS5 DualSense 手柄的 USB 波形触觉反馈，提供中文安装管理器。

当前版本：**0.9.1-beta.1（测试版）**。

已完成一次清理旧 Mod 后重新安装、进入游戏运行的用户测试，反馈正常。更多电脑、手柄与不同招式的体验仍待反馈。

## 下载

在本项目的 **[Releases（发行版）](https://github.com/CCMCHE/Wukong-DualSense-Haptics/releases)** 中下载 Mod ZIP，完整解压后先阅读“使用说明.txt”，再运行“安装管理器.exe”。

解压后的最外层只有：

```text
使用说明.txt
安装管理器.exe
配套文件/
```

安装器与“配套文件”应放在一起。

## 需要什么

- Windows 10/11 64 位与已安装的 PC 版《黑神话：悟空》。
- 原装 PS5 DualSense 手柄及支持数据传输的 USB 线。
- .NET Framework 4.8。
- [CSharpLoader 0.1.0 with hook](https://www.nexusmods.com/blackmythwukong/mods/664)：从作者页面手动下载原版 ZIP，再通过安装器导入；本包不内置加载器。

本触觉 Mod 不需要 UE4SS。当前版本使用 USB，未提供蓝牙或自适应扳机功能。DualSense Edge 未经实物验收。

## 安装

1. 正常退出游戏，完整解压 Mod 安装包。
2. USB 连接手柄，关闭该游戏的 Steam Input，不运行 DSX 等同时控制手柄输出的工具。Windows 声音输出保持为平时的耳机或音箱。
3. 双击“安装管理器.exe”，选择 `BlackMythWukong` 游戏根目录，或 `b1\Binaries\Win64`。
4. 如未安装兼容加载器，点击“下载 CSharpLoader”，下载 **with hook 0.1.0** 的原版 ZIP，再点击“导入原版加载器 ZIP”。
5. 点击“安装 / 更新触觉 Mod”。安装器自动检查并启用 `EnableJit=1`，需要修改时先备份，保留其他设置。
6. 安装成功后启动游戏，把游戏原生“手柄震动”调为 **0**，先走路、单次轻击命中敌人测试。

之后正常启动游戏即可，安装管理器不必常驻。加载器 Hook/JIT 与部分修改器可能不兼容，使用前请阅读其作者说明。

## 当前包含的反馈

- 普通攻击命中、轻棍第五式、不同棍势的重击。
- 蓄力、棍势升档与部分攻击过程。
- 走跑脚步、翻滚、精准闪避。
- 菜单操作、法术、变身进入与散去、精魄入口、喝酒与物品使用。

以上为当前代码包含的反馈范围；不同招式、形态及手感仍在测试中，不代表已完成全部逐项验收。

## 调力度、更新与卸载

在安装器中点击“打开配置与日志目录”，编辑 `WukongWaveHaptics.ini` 的 `Gain`。默认 `0.85`，允许范围 `0.1～1.0`，保存后约 2 秒生效。

更新或卸载程序时先退出游戏。安装器会保留可兼容的触觉配置，并在游戏根目录的 `WukongWaveHaptics_Backups` 保存安装前文件。

“卸载本触觉 Mod”保留加载器和其他 Mod，也不会把共享的 JIT 设置改回 0。卸载后可恢复游戏自身的震动设置。更多细节见“配套文件/详细说明.txt”。
